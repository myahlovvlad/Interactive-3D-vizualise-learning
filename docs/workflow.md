# Idea to Product
Статус: проект.
| Gate | Артефакты | Условие перехода |
|---|---|---|
| Discovery | problem brief, аудитория, интервью | проблема и критерий ценности сформулированы |
| Vision | PRD, PDR, ограничения | владелец подтверждает ключевые решения |
| Pedagogy | карта компетенций, misconceptions, задания | цели измеримы, задания связаны с целями |
| Prototype | UX, сцены, сценарии | проверены ключевые действия пользователя |
| Engineering | модели, геометрия, контракты, допущения | определены эталонные задачи и допуски |
| Development | исполняемый продукт, исходники | сквозной сценарий работает |
| Validation | научные, численные, UX и педагогические тесты | результаты и дефекты задокументированы |
| Packaging | сборки, инструкции, лицензии | проверены целевые среды |
| Go to market | landing, демонстрация, тест спроса | заявления подтверждены, метрики определены |
| Feedback | наблюдения, backlog, новые PDR | изменения прослеживаются до потребностей |

Интервью задаёт вопросы только по открытым решениям, сравнивает варианты, использует прототипы для проверки спорных предположений. Не перескакивать к массовой реализации при неопределённых критериях приемки.
