# Границы Alpha 0.1

P0: автономный Web/HTML, HS-GC-FID, общий граф и оба рендерера, инвентарь, материальный баланс, Headspace, EPC/тепловая модель, удерживание и моменты, FID, методика/очередь/SST, CDS, внешняя градуировка, базовая неопределённость и правило решения, диагностика, Tutorial/Practice, доказательное оценивание, LAB-008, экспорт/импорт/повтор. V1 для всех используемых моделей, V2 для критических моделей. Синтетический учебный профиль допускается, но не заявлять фармакопейную или экспериментальную валидацию.

P1/P2: расширение набора матриц, полный Monte Carlo/DoE, конечно-объёмный решатель, TCD/MSD, полный каталог работ, Studio, Tauri, MCP/REST/LMS, защищённая аттестация. Контракты расширения не означают пустые реализации.

Решения по поставке, требующие проверки G0: внешняя градуировка как минимальный путь LAB-008; внутренний стандарт и добавки сохраняются в целевом объёме. G16 и подтверждение идентичности обязательны для утверждений, которые их требуют; при отсутствии параметров сценарий ограничивается учебным предварительным заключением, а не выдаёт ложное подтверждение. G0 фиксирует точный набор аналитических методов и допустимых выводов; не сокращать утверждённый сквозной сценарий без ADR. HTML должен поддерживать файловый экспорт даже при ограничениях IndexedDB на file://. PDF/XLSX — экспортные расширения, минимальный пакет CSV/JSON и печатный HTML. Проверить эти предложения против пользовательских ADR; противоречия блокируют G0.

Аппаратная цель: 8 ГБ RAM; один вычислительный Worker, один тестовый Worker, последовательные сборки, Economy и fallback. Не требовать сервера или локальной LLM.
