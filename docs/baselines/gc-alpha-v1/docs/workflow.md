# LAB-008: сквозной эксперимент

Учебный HS-GC-FID остаточных растворителей в условной фармацевтической субстанции. Initial sample and standards seeded; hidden truth excluded from ordinary learner projections. Offline package cannot guarantee secrecy. Target analytes methanol, acetonitrile, dichloromethane, toluene, acetone, ethanol, ethyl acetate; actual coverage limited by parameter availability. G43 base; G16 confirmatory capability required for claims needing confirmation, otherwise conclusion explicitly limited. Normative profile version and source required; do not claim USP compliance with unverified method. Separate training protocol from actual normative procedure.

Workflow: assignment → sample registration → select versioned method → weigh, dissolve, aliquot, seal independent vials → configure GC and Headspace → readiness → SST → standards/QC → measurement sequence → raw signal → integration → identification → calibration → quantitative results → uncertainty and decision → report and evidence. Blank, SST, calibration, QC, sample and spike types. On failed SST block valid conclusion; preserve data and allow diagnosis. On abort save partial data and reason. Calibration range, residuals, matrix compatibility and uncertainty checked. No silent extrapolation. Source raw signal immutable; every integration version linked. Analytical decision may be indeterminate, according to versioned rule.

Inventory: balance, flask, pipette, vial, standard, reagent, crimper; mass, volume, purity and uncertainty; operations change conserved state. Faults: leak, nonhermetic vial, insufficient incubation, inlet contamination, flame failure; perturb physical state not just peak drawing. Explicit fault applicability and diagnostic evidence.

Visualization: macro workstation, instrument, capillary cross-section, statistical molecular view; closed/open, transparent, exploded, section, label. Actual calculated state drives movement and chromatogram; camera time independent. Provide keyboard and touch paths.

Education: Tutorial and Practice P0, basic Assessment evidence and explicit offline limits; Research and teacher studio expanded later. Diagnostic prerequisite graph; objectives, misconception map, worked examples, 3 hints, transfer tasks, rubric. Assess observable practical actions and results; do not score speed as mastery. Critical errors (invalid SST, unsupported identity, wrong mass conversion, invalid calibration, data integrity) block success. Proposed 80% rubric threshold; sample pilot 10–20, pre/post equivalent forms, transfer, delayed 14-day check, record exclusions and uncertainty. Not a proof of broad effectiveness. Provide text alternatives, accessible labels, keyboard and captions.

Experiment bundle: manifest, config/method snapshots, parameter provenance, sample operations, seeds, sequence, raw signal, integration versions, calibration, uncertainty, decision, events, reports, checksums. Export CSV/JSON and human-readable report (printable HTML minimum; PDF/XLSX follow scope agreement). Import and replay same scientific results within stated tolerance; record code/solver versions. Report labels synthetic vs imported vs simulated, missing evidence and limitations. No real quality certificate.
