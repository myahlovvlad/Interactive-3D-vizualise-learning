# Аналитическая лаборатория STEM — оболочка 0.1.0

## Назначение и границы

Платформа предоставляет единый интерфейс для просмотра каталога и запуска существующих учебных симуляторов. ГХ 0.0.2 и ВЭЖХ 2.0 подключены как автономные HTML-модули (`legacy-html`), без изменения их научных алгоритмов. Это не общий вычислительный Runtime и не подтверждение экспериментальной валидации. Решения GC-ADR-001–122 сохраняют силу; G0–G2 не закрыты.

## Структура

- `catalog.json` (версия схемы 2) — единственный источник сведений о приборе, категории, статусе, вариантах, пути и версии модуля.
- `packages/platform-shell/registry.js` — проверка реестра, фильтрация, разрешение маршрута `#lab=<id>`, управление жизненным циклом модуля через `mount/unmount`.
- `apps/platform/` — русскоязычная оболочка: шаблон, CSS и контроллер интерфейса. Только один активный iframe; при возврате он удаляется вместе с вычислительным контекстом. Несохранённые данные симулятора могут теряться — предупреждение отображается в рабочем пространстве.
- `tools/build-platform.cjs` — воспроизводимая сборка HTML без сторонних библиотек; встраивает реестр, оболочку и разрешённые локальные HTML-артефакты. `index.html` автономен; отдельный модуль можно скачать из рабочей области.
- `tests/platform.test.cjs` — контракт реестра, корректность маршрутов и жизненного цикла, проверка актуальности сборки.
- `tests/platform-browser.py` — сценарии в Chromium; отдельный тест без внешних сетевых запросов.

## Контракт расширения

Запись `prototype` требует существующего относительного пути HTML, уникального id, категории, версии модуля и `kind: legacy-html`. Запись `planned` имеет `path: null` и `module: null`, не запускается. Новая модель добавляется через реестр и повторную сборку. Встраиваются только доверенные артефакты из репозитория, произвольный пользовательский HTML не принимается. Модули работают в iframe без строгой изоляции безопасности; это локальный учебный продукт, а не хостинг недоверенного кода. Варианты приборов на карточке не являются реализованными функциями, если не обозначены явно.

## Сборка и проверка

```sh
node tools/build-platform.cjs
node tools/build-platform.cjs --check
node --test tests/platform.test.cjs
python tests/platform-browser.py  # Python + Playwright + Chromium
```

Для обычного пользователя — скачать `index.html` и открыть в браузере. Для браузерной проверки локальный Chromium в окружении разработки блокировал навигацию file:// и HTTP на localhost политикой администратора; проверялось содержимое точного HTML через Playwright `set_content`, в том числе фактический GC Worker, элементы ВЭЖХ и побайтово идентичный экспорт отдельного модуля. Прямой запуск файла, реальные измерения RAM на ноутбуке, GitHub Pages, научная валидация и общая система хранения экспериментов не подтверждены.

## Следующий инженерный срез

1. Завершить G0/G1 ГХ и мигрировать динамический расчёт из JavaScript-прототипа в имеющееся TypeScript Application API.
2. Извлечь общий контракт состояния эксперимента, временной шкалы, сигнала и графа компонентов; доказать повторное использование на ГХ и ВЭЖХ.
3. Реализовать первый предметный вертикальный срез спектрофотометрии (однолучевая оптика, фотометрия, проверяемый закон поглощения), затем расширять детекторы и приборы. Не подменять отдельные научные модели общими анимациями.
