# Библиотека аналитических приборов

Расширение целевой архитектуры STEM-платформы. GC Alpha 0.1 и 122 утверждённых ADR сохраняют силу. Каталог `catalog.json` — источник статусов и путей. Прототипы находятся в `prototypes/`; они не являются реализациями общего TypeScript Runtime.

| Домен | Первый вертикальный срез | Следующие расширения |
|---|---|---|
| ГХ | HS-GC с ПИД, температура, газовый поток, сигнал | ТКД, ЭЗД, МС, ПФД, ТИД; отдельные модели отклика и необходимые газовые линии |
| ВЭЖХ | УФ, насос, клапан, колонка, градиент | ДМД, флуориметрия, рефрактометрия, МС |
| УФ/Вид | Однолучевая фотометрия, спектр, эталон | Двухлучевая схема, градуировка, кинетика, контроль характеристик |
| Ионная хроматография | Ионообменное разделение, кондуктометрия | Подавление фоновой проводимости, градиент, катионы/анионы |
| Капиллярный электрофорез | Электрофоретическая подвижность и электроосмос | CZE, MEKC, CGE, другие режимы после предметной проверки |
| Амплификатор | Тепловой цикл и модель амплификации | qPCR, кривые флуоресценции, Cq, контроли |
| Секвенатор | Сначала выбрать принцип измерения | Сэнгер и NGS — разные архитектуры и модели, не один универсальный решатель |

## Общие контракты (проект)
InstrumentDescriptor: id, version, capabilities, componentGraph, methodSchema, modelRefs, sceneRefs, learningRefs.
Component: id, parentId, geometry, mount, ports, stateMachine, sourceRefs.
SimulationRequest: instrumentId, modelVersion, methodSnapshot, seed, inputs, provenance.
SimulationSnapshot: virtualTimeS, componentStates, observableChannels, diagnostics.
DetectorModel: compatibleInstrument, physicalInputs, units, response, validityDomain, referenceTests.
Renderer: loadScene(graph), update(snapshot), select(componentId), dispose().
ExperimentPackage: version, method, rawSignal, derivedResults, events, hashes.

Контракты пока предложены, не реализованы. Стабильные машинные идентификаторы не переводятся; подписи и диагностика локализуются отдельно. Научные решатели независимы от визуализатора; предметные модели отклика не заменяются универсальной гауссовой кривой. Сначала доказать общий контракт на ГХ и ВЭЖХ, затем извлекать универсальные компоненты. Один Worker, Economy, автономный HTML, последовательные тесты на целевом ноутбуке 8 ГБ. Новые предметные домены — backlog, не расширение обязательного LAB-008.

## Импорт
ГХ 0.0.2 — отдельный JavaScript-прототип; оригинальный Colorfigures и WebGL отсутствуют. ВЭЖХ 2.0 — предоставленный пользователем HTML, сохранена исходная научная логика, локализованы видимые подписи. Проверка интерфейса не доказывает научную валидацию. G0–G2 открыты. Публикация HTML не означает настройку GitHub Pages.
