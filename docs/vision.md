# Product Vision
Статус: проект на основании [решений раунда 1](decisions/round-01.md).

Миссия: превращать идеи в воспроизводимые интерактивные научно-образовательные и инженерные продукты для всех STEM-дисциплин. Пользователь совместно с агентом уточняет потребность, проверяет прототип, редактирует модель, проектирует обучение и задания, валидирует продукт, упаковывает и продвигает его.

Целевые группы (гипотезы): авторы курсов, преподаватели, учащиеся, инженеры, производители оборудования. Приоритетный сегмент и готовность платить ещё не проверены.

Ценность: одна проверяемая модель поддерживает реалистичную 3D-сцену, абстрактную визуализацию, графики, формулы, эксперимент, оценивание и экспорт. Продукт должен работать без обязательного участия LLM в исполнении.

Границы: универсальная архитектура не означает поддержку всех дисциплин в Alpha. Не обещать точность CAE без верификации и валидации. Не считать фотореализм доказательством достоверности.

Модель распространения: открытое ядро и коммерческие продукты/модули; конкретные лицензии, границы IP, цены и каналы требуют отдельного утверждения.
