# Alpha 0.1 — рамка принятия решения
Статус: продукт не выбран.
Согласно PDR-006 первый релиз доказывает полный цикл Idea to Product одним завершённым продуктом. Кандидаты: виртуальная ВЭЖХ, оптический тренажёр, механический/тепловой эксперимент. Выбор по доступности эталонных данных, учебной ценности, стоимости разработки, спросу и покрытию архитектурных рисков.
Предлагаемые критерии: один сквозной маршрут автора от интервью до сборки; редактируемая сцена; работающая модель с эталонными тестами; учебный маршрут с заданиями и обратной связью; автономный runtime; проверенная сборка минимум одной целевой платформы; демонстрация и гипотеза распространения. Численные пороги и целевые платформы согласовать в следующем раунде.
Не считать универсальную Studio, полный набор CAE или пять нативных платформ обязательными до отдельного решения. Не заявлять коммерческий успех без свидетельств спроса.
