# MWP 0.0.2 — Dynamic GC & Living Instrument

Open index.html offline. Rebuild with `python build.py`, test with `node --test tests/*.cjs`. Browser check: `python tests/browser.py` (Playwright + Chromium). This is an additive independent JS prototype, not yet integrated with the TypeScript Application API of 0.0.1. No original Colorfigures code is included. Geometry is a conceptual orthographic SVG projection of 3D boxes and paths; depth sorting is approximate. No WebGL, validated CAD, collision checks or full visual regression. The model uses a synthetic HS partition coefficient shared by three illustrative analytes, first-order equilibration, ideal loop/split without depletion or pressure correction, quasi-steady compressible gas flow, first-order oven response to setpoint, midpoint integration of retention in an integrated pressure coordinate, Gaussian FID with approximate exit-time efficiency. No EPC dynamics, full moment transport, physical thermal PID, independent experimental validation or G0/G1 approval. JSON export only; no import in this version. Geometry and animation consume calculated snapshots. One worker, no external assets. Tests do not establish performance on 8 GB hardware. Preserve prior baseline and 0.0.1.
