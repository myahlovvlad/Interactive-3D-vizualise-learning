# ВЭЖХ 2.0

Импорт пользовательского HPLC_Virtual_Lab_2(1).html с локализацией интерфейса. Научные формулы и логика расчёта не изменены. Исходный прототип использует Canvas, условные параметры удерживания, градиент в приближении однородного состава, учебную оценку давления и отклика. Не валидирован экспериментально и не интегрирован в общее TypeScript-ядро. См. browser.log; проверка интерфейса не является научной верификацией.
